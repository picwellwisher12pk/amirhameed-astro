# Features & Enhancements

- [x] **Interactive Particle Sandbox**: Dedicated GPU-accelerated laboratory at `/playground#particle-sandbox` allowing visitors to upload custom photos (file picker + drag & drop), test 8 organic hover/displacement interaction modes, adjust real-time physics parameters (repel force, cursor radius, particle size, animation speed, effect intensity), capture high-res snapshots, and toggle fullscreen.
- [x] **Complete Design Portfolio Integration**: Parsed and imported 62 design projects from WordPress `x-portfolio` export (covering 3D, branding, illustration, character design, web design, print, and photography) with full image previews and graceful error fallback, presented alongside modern apps with a 2-tier scope switcher (All Works, Apps & Software, Design Portfolio).
- [x] **Creative Lab & Experiments**: Integrated typography studio (19 fonts), Urdu bilingual script comparator, and inline editable component prototype.
- [x] **Responsive & Mobile Optimization**: Cursor physics scoped to fine-pointer devices (`@media (hover: hover)`), touch-friendly mobile drawer menu, and adaptive particle density.
- [x] **URL Deep Linking & Filter Persistence**: Direct shareable URLs for every portfolio and blog category (e.g., `/projects?category=3d`, `/projects?category=branding`, `/projects?scope=design`, `/projects?category=digital-painting`) with full slug & case-insensitive resolution. Browser remembers active category and scope on refresh via `localStorage` and supports native browser Back/Forward navigation (`popstate`).
- [x] **Metro Bento Grid Portfolio**: Modular Windows Metro / Modern Bento-style grid with dynamic asymmetric tile sizing (`grid-auto-flow: dense`), giving featured masterworks double-width & double-height immersive tiles (`col-span-2 row-span-2`), wide showcase cards (`col-span-2`), and standard modular tiles (`col-span-1`), seamlessly adapting between desktop and mobile with smooth hover transitions and category filtering.
- [x] **High-Resolution Software & App Work Previews**: 10 bespoke high-resolution UI preview artworks created and embedded across all modern software and web application projects (`censor-flow`, `excited-gem`, `hadith-app`, `quran-verse-identifier`, `gem-harvester`, `design-system-craft`, `youtube-addons`, `screenshot-react-vite`, `paxamir`, `qaweet`).
- [x] **WordPress Shortcode & Gallery Sanitization**: Sanitized all legacy WordPress shortcodes (`[cs_content]`, `[cs_section]`, `[cs_row]`, `[cs_column]`, `[cs_text]`, `[x_blockquote]`, `[x_button]`) and converted `[gallery ids="..."]` to native responsive Markdown images mapped via XML attachment metadata.
- [x] **Version Tracking**: Bumped project release version to `0.3.0` in `package.json`.

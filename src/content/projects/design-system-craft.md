### Overview
Modern web portfolios often fall into two extremes: either generic minimalist monochrome templates, or bloated experimental playgrounds with poor readability. 

The **Luxury Classical & Aurora Design System** was architected to bridge fine editorial aesthetics with robust frontend engineering. It unifies high-contrast typography, custom HSL color tokens, micro-spring cursor dynamics, and GPU-driven particle visual physics into a harmonious component library.

### Key Features & Architecture
- **Multi-Theme Token Architecture**: Dynamic CSS custom property matrices allowing seamless shifts between modern studio, cyber monospace, editorial serif, and luxury classical modes without layout shift.
- **Micro-Spring Physics & Kinetic Cursors**: Spring-damped trajectory tracking scoped to fine pointer devices (`@media (hover: hover) and (pointer: fine)`), preventing touch interference on mobile devices.
- **Bilingual Typographic Harmony**: Custom baseline alignment pairing Google Fonts with RTL Urdu calligraphic typefaces (Noto Nastaliq Urdu, Jameel Noori, and Vazirmatn).
- **Responsive Layout System**: Mobile-first grid architecture with adaptive typography scaling from ultra-wide displays down to mobile viewports.

### Tech Stack & Learnings
- **Astro 7 & Tailwind CSS v4**: Leveraging Vite-powered CSS compilation and zero-runtime static content generation.
- **WebGL & Custom GLSL**: High-density particle gathering with 8 switchable organic interaction modes (Volumetric Aura, Silk Ripple, Gravitational Lens, and Neural Constellation).
- **Design Tokens**: Standardized spacing, border radiuses, and depth elevations adhering to clean-code principles.

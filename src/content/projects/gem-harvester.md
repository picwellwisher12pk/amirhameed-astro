### Overview
**Gem Harvester** is a browser-based automation tool engineered to streamline web scraping and data harvesting. It allows users to visually point-and-click on page elements, extract repetitive card data or tabular structures, and export clean JSON and CSV files.

### Key Architecture & Capabilities
- **Visual Element Selector**: Custom DOM highlighter and XPath/CSS selector generator that identifies repeating patterns automatically.
- **Pagination & Infinite Scroll Crawler**: Handles multi-page traversal with customizable crawl rate-limits to prevent bot detection.
- **Enterprise UI**: Built on React 18 and Ant Design within the Plasmo framework.

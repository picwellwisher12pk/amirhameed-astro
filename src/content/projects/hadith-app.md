### Overview
**Hadith Reader** is a multi-platform application (Web & Mobile) engineered for studying, researching, and referencing classical collections of prophetic traditions (Sahih Bukhari, Sahih Muslim, etc.) with comprehensive commentary and multi-language support.

### Key Architecture & Capabilities
- **Cross-Platform Shared Core**: Next.js App Router for the desktop web experience paired with React Native / Expo for iOS and Android.
- **Data Modeling & Storage**: High-performance database layer with Prisma ORM querying thousands of indexed narrations hosted on Supabase (Postgres).
- **Personalized Cloud Sync**: User authentication, reading progress, categorized bookmarks, and custom notes synchronized across all user devices.

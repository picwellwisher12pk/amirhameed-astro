### Overview
**Qaweet (QA Suite)** is an end-to-end quality assurance and browser automation monorepo designed to test web applications, inspect dynamic DOM states, and validate cross-browser behavior across Chrome and Firefox.

### Key Architecture & Capabilities
- **Bun Monorepo Architecture**: Clean separation of concerns between the browser extension core (`qa-extension`) and the companion web sandbox (`qa-web`).
- **Cross-Browser Manifest V3 & Firefox Support**: Shared codebase compiling targeting multiple browser vendor runtimes.
- **Fast Execution Engine**: Powered by Bun runtime for ultra-fast packaging and zero-overhead test execution.

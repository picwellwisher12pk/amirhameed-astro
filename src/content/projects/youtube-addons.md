### Overview
**YouTube Addons** supercharges the YouTube experience by introducing fine-grained video bookmarking with notes, chapter annotations, custom local playlists independent of YouTube's algorithm, and automated export/sync capabilities.

### Key Architecture & Capabilities
- **WXT Extension Framework**: Built on the next-generation WXT framework with TypeScript and React 18 for high compile speed and MV3 compliance.
- **Reactive State with Preact Signals**: Lightweight, fine-grained state reactivity ensuring zero UI jank when injecting widgets directly into the YouTube DOM.
- **Accessible UI Primitives**: Built using Radix UI headless components styled with Tailwind CSS for seamless integration with YouTube's native dark mode.

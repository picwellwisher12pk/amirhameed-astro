There are no true rules in reading. Apart from the visual process which we all share, everything else is utterly intimate and subjective. It can be anything from glancing, scanning, browsing, leafing, watching; some times, it’s selective and non-linear, it’s all about identifying keywords. Other times, it’s conceptual, reflective, it’s in-depth. Slow, fast, precise, functional, symbolic, social, cultural, reading is as diverse an activity as we are many. via [Hack the – The Pastry Box Project](https://the-pastry-box-project.net/sorin-pintilie/2014-August-25).

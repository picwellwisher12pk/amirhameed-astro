Every project is made up of countless little changes. With a little luck, they will finally form a website, an app, or some other product. Your version control system keeps track of these changes. But only once you understand how to read them will you be able to track your project’s progress. Using the example of Git, the popular version control system, this article will help you understand these changes. via [Understanding Version Control with Diffs](http://www.sitepoint.com/understanding-version-control-diffs/?utm_content=bufferd6c30&utm_medium=social&utm_source=facebook.com&utm_campaign=buffer).

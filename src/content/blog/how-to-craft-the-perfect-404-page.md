Chances are, if you’ve never hit a 404 page, you’ve probably never used the internet. The concept is simple: If a client computer requests a URL that the server can’t resolve, the server responds with the ‘404 Not Found’ response – or in other words “Yes, I’m here, but I can’t find the item you requested”. via [How to Craft the Perfect 404 Page](http://www.sitepoint.com/craft-perfect-404-page/).

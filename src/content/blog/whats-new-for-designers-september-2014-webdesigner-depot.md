The September edition of what’s new for web designers and developers includes new web apps, CSS tools, software, email templates, inspiration resources, productivity apps, jQuery resources, pattern tools, and some really great new fonts. Many of the resources below are free or very low cost, and are sure to be useful to a lot of designers and developers out there. As always, if we’ve missed something you think should have been included, please let us know in the comments. And if you have an app or other resource you’d like to see included next month, tweet it to @cameron_chapman for consideration. via [What’s new for designers, September 2014 | Webdesigner Depot](http://www.webdesignerdepot.com/2014/09/whats-new-for-designers-september-2014/?ref=facebooksp).

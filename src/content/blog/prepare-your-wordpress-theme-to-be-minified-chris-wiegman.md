Minifying your WordPress themes is one of the best things you can do to help reduce the number of http calls made to the server and thus help reduce the loading time of your site. There are two excellent plugins which can do the actual work for you, W3 Total Cache and WP Minify both of which will take the Javascript files and style sheets in your theme and plugin output and combine them into a single javascript file and a single stylesheet. In the case of a complex theme or a site with many plugins this technique alone can easily save 10 or more http requests and provide a noticeable decrease in load times. via [Prepare Your Wordpress Theme To Be Minified | Chris Wiegman](http://www.chriswiegman.com/2011/04/prepare-your-wordpress-theme-to-be-minified/).
